How to practice
  1. Read the mission and examples. Keep the supplied function names.
  2. Replace the comments or pass with your code. Indent blocks by four spaces.
  3. Press Run to try a sample. For functions, add print(your_function(...)).
  4. Press Check challenge to run all cases. Read the failing input, expected value, and your actual result.
  5. Use hints, fix your code, and retry. Mistakes do not deduct XP. A mission awards XP once.

Use Mission / Code / Results above the workspace. The Indent and symbol buttons help when your keyboard has no Tab key. Landscape gives the editor more space. You can pinch to zoom.
Python workspace
Run always starts main.py. Add helpers.py, then use import helpers. Files are kept per mission. Free lab is a separate workspace. Input is supplied before a run. Trace records line execution and variable snapshots; Stop ends the Python worker.
This is real CPython in your browser. Common standard-library modules, functions, classes, and data structures work. Desktop GUI libraries such as Tkinter and a full operating-system terminal are not available. Extra package installation is not part of this lab.
Offline
The browser downloads app files for offline use automatically. Wait for Offline ready on the game screen before disconnecting. Keep the same address and browser. Offline access stores the app, not student work. Save file to keep your own progress.
Two modes
Python Lab Mode opens this IDE directly. Choose mode returns to the opening screen, where Story Mode starts the adventure. Manual saves only · each new visit starts fresh. During a story challenge, close the editor to return to your explorer.
Useful shortcuts
Ctrl/Cmd+Enter: Run · Ctrl/Cmd+S: save current .py · Ctrl+Space: suggestions · Ctrl/Cmd+F: find · Ctrl/Cmd+/: comment · Esc: leave the editor. Suggestions are basic Python keywords and names, not full type analysis.
